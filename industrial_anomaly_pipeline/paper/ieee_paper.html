Abstract -Industrial cyber-physical systems deploy continuous sensor arrays across rotating machinery, processing lines, and turbofan engines. Screening high-frequency multivariate time-series (MTS) streams for anomalies requires strictly bounded processing latencies. This paper evaluates a streaming MTS anomaly detection pipeline designed to meet a sub-20ms per-window latency Service Level Agreement (SLA). The system couples an asynchronous ingestion layer featuring explicit backpressure management to two analytical engines operating behind a unified detector interface: a closed-form Dynamic Mode Decomposition (DMD) with Seasonal-Trend (STL) decomposition engine, and an unsupervised PyTorch LSTM/Dense Autoencoder. Scoring is performed via an evaluation engine that combines reference-centroid Euclidean distance with model error using an epsilon-guarded harmonic mean under dynamic threshold recalibration. System evaluations on the NASA C-MAPSS turbofan dataset and a synthetic five-channel Tool Condition Monitoring (TCM5) dataset demonstrate SLA compliance at nominal throughput for both analytical engines (DMD p99 = 0.20–0.47ms; LSTM Autoencoder p99 = 2.7–3.2ms). Under extreme burst load scenarios, the DMD engine maintains p99 latency under 15ms via backpressure load shedding, whereas the Autoencoder engine degrades to 150–180ms p99 latency.

Index Terms—real-time anomaly detection, multivariate time series, dynamic mode decomposition, autoencoder, streaming ingestion, industrial IoT, SLA benchmarking

I. Introduction

Modern industrial facilities rely on sensor arrays monitoring correlated operational variables sampled at high frequencies. Identifying emerging mechanical faults—such as bearing degradation, spindle overloading, or control loop instability—requires continuous processing of streaming multivariate time series (MTS). Deploying anomaly detection within industrial control environments imposes two main operational constraints:

  1. Hard latency constraints. Real-time alert pipelines require processing latencies on the scale of tens of milliseconds per window, inclusive of ingestion, sliding window assembly, and inference.
  2. Label scarcity. Anomalous operational states occur infrequently and are rarely labeled prior to failure, necessitating unsupervised modeling of baseline normal dynamics.

Statistical process control methods provide low computational latency but struggle to capture non-linear, cross-channel interactions. Conversely, deep reconstruction architectures, such as LSTM encoder-decoders [2] and autoencoder variants [1], [7], model complex non-linear relationships by quantifying reconstruction error against learned normal baselines. Dynamic Mode Decomposition (DMD) [3] and Seasonal-Trend decomposition using Loess (STL) [4] offer an alternative linear fast-track approach, utilizing closed-form linear operators and decomposition matrices to isolate residual dynamics without iterative optimization.

While existing literature focuses heavily on offline classification metrics (such as F1 score and AUC-ROC) evaluated on pre-segmented datasets, production deployment depends on streaming systems dynamics. Ingestion queueing, backpressure propagation, dynamic threshold drift, and thread pool exhaustion dictate runtime stability in operational environments [9].

This paper presents a streaming MTS anomaly detection pipeline configured to benchmark linear mathematical and deep learning models within an identical ingestion framework. We evaluate the trade-offs between linear closed-form execution and non-linear deep reconstruction regarding processing latency, memory stability, and detection performance across nominal and burst throughput conditions on the NASA C-MAPSS dataset [5] and a synthetic Tool Condition Monitoring stream.

The remainder of this paper is structured as follows. Section II reviews related research. Section III details the system design, mathematical models, and scoring mechanics. Section IV covers edge-case handling and concurrency controls. Section V presents empirical benchmark results. Section VI concludes with future research directions.

II. Related Work

Reconstruction-based deep anomaly detection. Malhotra et al. [2] implemented LSTM encoder-decoder architectures to compute reconstruction errors for multi-sensor time series. Hundman et al. [1] expanded deep reconstruction approaches to NASA SMAP/MSL spacecraft telemetry using dynamic non-parametric thresholding. Sakurada and Yairi [7] demonstrated autoencoder-based non-linear dimensionality reduction for anomaly detection, establishing the foundation for Dense autoencoders as computationally reduced alternatives to sequential models.

Closed-form spatiotemporal modeling. Schmid [3] formalized Dynamic Mode Decomposition (DMD) to extract spatiotemporal modes from linear systems using truncated Singular Value Decomposition (SVD). DMD provides a closed-form, non-iterative linear model fit. Cleveland et al. [4] introduced the STL decomposition framework to partition series into trend, seasonal, and residual components. Combining DMD with STL enables fast computation of spatial residual energy and temporal deviations.

Benchmark Datasets. The NASA C-MAPSS turbofan dataset [5] simulates run-to-failure degradation trajectories. In anomaly detection research, remaining useful life (RUL) trajectories are mapped into binary anomaly windows corresponding to near-failure degradation regimes.

Streaming Systems. Ren et al. [9] outlined operational metrics for time-series anomaly detection deployed in cloud infrastructure, emphasizing processing latency and online threshold adjustments. This study analyzes these streaming properties under controlled worker load and backpressure settings.

III. System Architecture & Methodology

A. Overview

The processing architecture consists of four distinct stages:

SensorStreamProducer(s) --(bounded asyncio.Queue)--> StreamConsumer | asyncio tasks, non-blocking | sliding-window | overflow policy: block / drop_oldest / drop_new | assembly, bounded v | in-flight semaphore Sanitized SensorPacket v ThreadPoolExecutor -> BaseAnomalyDetector | Engine 1: DMD+STL | Engine 2: LSTM/Dense AE v CompositeScoringEngine harmonic-mean(distance, local_error) + DynamicThresholder v LatencyTracker + Evaluation Metrics

B. Ingestion and Concurrency Layer

The ingestion module (SensorStreamProducer) simulates continuous multi-sensor telemetry emitting to a bounded non-blocking queue. Three queue overflow management strategies are supported: block, drop_oldest, and drop_new. Non-finite values (NaN/Inf) undergo causal, per-channel exponential moving average imputation at ingress.

The StreamConsumer consumes packets from the queue, constructs sliding windows of dimension (window_size, n_features), and routes complete windows to execution workers via a thread pool executor. To prevent unbounded memory growth during high-throughput bursts, in-flight execution tasks are restricted using an asynchronous semaphore bounded by worker capacity. Saturating the worker pool halts window dispatching, causing queue fill and upstream backpressure propagation to the producers.

C. Engine 1 — DMD + STL

Given a snapshot matrix containing T continuous multivariate samples x1,…,xT ∈ ℝn for n channels, the paired matrices are defined as:

X = [x1, …, xT−1],   X′ = [x2, …, xT] ∈ ℝn×(T−1).   (1)

DMD identifies the best-fit linear operator A ∈ ℝn×n mapping X to X′. Utilizing a rank-r truncated SVD where X ≈ UrSrVr⊤, operator A is computed via:

Ã = Ur⊤X′VrSr−1,   A = UrÃUr⊤.   (2)

Diagonal values of Sr are clamped at ε = 10−8 to prevent numerical instability under near-zero variance. During inference, one-step reconstruction error over incoming windows serves as the primary linear error metric.

In parallel, channel values undergo STL decomposition [4] into trend, seasonal, and residual components. The relative residual energy is aggregated with the DMD prediction error using equal weighting (α = 0.5) to produce the Engine 1 score.

D. Engine 2 — Deep Reconstruction (LSTM / Dense Autoencoder)

Engine 2 implements deep reconstruction architectures. The suite evaluates two variants: an LSTM encoder-decoder suitable for variable sequence inputs, and a Dense autoencoder operating on flattened fixed-length window vectors. Models are trained on baseline normal data using MSE loss and early stopping. Inference executes under disabled gradient computation modes.

E. Evaluation Engine — Composite Scoring & Dynamic Thresholding

Window anomaly scores combine distance metrics and model residual errors using an epsilon-guarded harmonic mean:

score(w) = 2 · d(w) · e(w)d(w) + e(w) + ε,  (3)

where d(w) represents the minimum Euclidean distance between window sample states and k reference cluster centroids fit on normal data, e(w) denotes model error, and ε = 10−8 prevents division by zero. The harmonic mean ensures high scores require deviations across both spatial state distance and model residual metrics.

Thresholding is managed dynamically via a rolling baseline computed over recent non-anomalous window scores (μ + kσ). If consecutive windows trigger positive detections exceeding a run limit (default 50 windows), the threshold re-initializes to accommodate baseline operational drift.

IV. Robustness & Implementation Details

System stability under continuous streaming requires explicit handling of numerical and state edge cases:

Worker Pool Queue Management. Standard thread pool execution mechanisms utilize unbounded submission queues. Under high input frequencies, queue size growth causes memory expansion. Restricting concurrently active tasks via worker semaphores enforces upstream backpressure propagation through the ingestion queue.

Matrix Dimension Validation. Input shapes are validated prior to linear algebra transformations. In dense neural networks requiring static input dimensionalities, mismatched window lengths raise explicit exceptions. Missing or single-frame non-finite readings are imputed using pre-calculated feature means.

Baseline Maintenance. Sustained operational state shifts can cause non-anomalous baseline drift, leading to continuous detection triggers. Suppressing threshold updates during flagged windows prevents anomaly contamination of the baseline, while the forced reset threshold handles genuine operating regime shifts.

V. Empirical Evaluation

A. Experimental Setup

Benchmarks were conducted on single-threaded execution environments using a unified sliding window configuration (window length 30, stride 5, 15% validation split):

NASA C-MAPSS (FD001): Turbofan engine degradation dataset containing 16 active sensor channels. The final 30 operational cycles of test trajectories are designated as anomalous. The dataset comprises 2,993 training, 528 validation, and 2,614 test windows.

TCM5 (Synthetic): A five-channel Tool Condition Monitoring stream (spindle load, vibration, temperature, acoustic emission) containing synthetic tool wear shifts. The dataset yields 1,016 training, 179 validation, and 595 test windows.

VI. Conclusion & Future Work

This paper evaluated a real-time multivariate time-series anomaly detection system under latency and throughput constraints. A closed-form DMD+STL engine was compared against deep autoencoder architectures across nominal and burst ingestion loads. Experimental results indicate that while deep autoencoders provide flexible modeling for complex series, closed-form linear operators maintain SLA compliance under severe ingestion bursts where neural inference queues saturate available compute capacity.

Future work includes implementing adaptive execution routing to process nominal windows via closed-form linear models while selectively routing out-of-bounds candidates to deep networks. Additional research will focus on trend-sensitive distance metrics to improve detection performance on continuous degradation trajectories.
